🛒 Grocery Price Comparison App

Compare prices across Israeli supermarkets, auto-fill cart, get a confirmation link.

Full Product Vision

  1. Persist order history — track past purchases per vendor with barcodes, build a personal product DB over time
  2. Image-based grocery lists — send photo of handwritten Hebrew list → vision/OCR maps to products in DB
  3. Compare prices across Shufersal Rami Levy Victory
  4. Delivery windows — show available delivery times per vendor
  5. Auto-fill cart — browser automation adds items to chosen vendor's cart
  6. Confirmation link — user just clicks to confirm the pre-filled order
  7. Deals & alternatives — current promotions, suggest cheaper substitutes
  8. Shared lists — spouse can add items with real-time notifications

POC Scope (First Build)

Prove that we can:

  1. Compare prices across all 3 vendors
  2. Fill a cart on the chosen vendor's website automatically
  3. Give the user a link to confirm the order manually

Vendor Integration Details

Rami Levy — Direct HTTP API Easiest

Reverse-engineered REST API documented via rami-levy-mcp project.

  • Search: POST /api/catalog {"q":"term","store":"331"}
  • Cart: POST /api/cart with product IDs + quantities
  • Auth: Bearer token + ecomtoken + cookie from browser localStorage
  • Response: id, name, barcode, price, images, availability

Token extraction: Playwright opens login page → user logs in → script reads localStorage.ramilevy.

Auto-refresh: detect 401 → re-authenticate via headless Playwright.

Shufersal — Playwright Automation Harder

No public API. Confirmed by shufersal-mcp project (uses Puppeteer).

  • Persistent Playwright browser context (saves login session)
  • First run: browser opens, user logs in manually, session saved
  • Search: intercept XHR responses (preferred) or DOM scraping fallback
  • Cart: search each product → click "Add to Cart" → set quantity

Victory — Playwright Automation Harder

Runs on stor.ai white-label platform. No API docs.

  • Same persistent browser context pattern as Shufersal
  • Discovery: playwright codegen https://www.victoryonline.co.il
  • XHR interception with DOM scraping fallback

Key Technical Findings

🏛️ Government Price Data (Free, No Auth)

Israel's 2014 transparency law requires all major chains to publish machine-readable XML price data.

  • Python packages: il-supermarket-scraper + il-supermarket-parser
  • Fields: ItemCode (barcode), ItemName, ItemPrice, Manufacturer, UnitOfMeasure
  • Perfect for Phase 1 — prove comparison works with zero risk

🔗 Product Matching Strategy

TierMethodConfidence
1Exact barcode (EAN-13) matchGold standard
2Fuzzy Hebrew name match (rapidfuzz token_sort_ratio ≥ 65%)Good
3Personal history match (future — use past purchases)Improves over time

Challenges: store brands, weight vs unit, pack sizes, Hebrew morphology (prefix letters).
